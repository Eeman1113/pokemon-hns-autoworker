An autoplay option for Pokémon Heart & Soul, in the start menu under SAVE. Hand it the controls for the grinding; press B and you have them back.

The patcher checks the CRC32 before doing anything. A different region, a trimmed dump or an already-patched ROM is rejected up front rather than producing a broken file you discover hours later.

What it does

Plays the battles itself
It picks moves by expected damage — power, type effectiveness, STAB and accuracy — rather than hammering the first option. The obvious approach was to point the game's own opponent AI at your side; that was tried and abandoned because it hard-freezes the console, and because when it did run it played worse: that AI assumes a full team it can switch and set up with, which is losing play for one Pokémon that never switches. Measured against button-mashing in wild battles: zero faints instead of one, and 21% fewer frames per battle.
Knows where it is in the story
The whole route is pre-declared as an ordered table of objectives. On hand-off the agent reads your save file's own flags to find the furthest point it can prove you have reached, and resumes there. A fresh file and a nine-hour save take the same code path.
Gives control back instantly
The agent writes only the remapped key fields and reads your input only from the raw hardware register, so a real B press can never be confused with one of its own. The A+B+START+SELECT soft reset also keeps working, because raw keys are never touched.
Cannot touch your save
The agent is structurally forbidden from saving. That one rule turns every possible bug from "ruined save file" into "reset and lose the session".

Honest status

It plays the opening of the game by itself and then stops. That is the whole claim. Everything below is either measured or marked unmeasured.

Works, with evidence Menu entry · stage detection (resumes from any save by reading its flags) · cross-map routing through doors, warps and map connections · hands control back on B within one frame · cannot touch your save file · survives a white-out and carries on · routes to a Pokémon Centre when hurt
Route data45 main-line objectives — 41 derived from the game's own scripts, 3 unknown — with 44/44 target coordinates verified against the map layouts
BattlesChooses moves by expected damage. Measured in wild encounters: zero faints and 21% faster than button-mashing. Gym leaders are unmeasured — see below
PuzzlesAll three former stopping points solved. Ice Path needed no solution at all: measurement showed its ice does not slide in normal play, so it is an ordinary walk
Does not doFinish the game. Switch Pokémon or use items in battle. Catch or train anything

How far it actually gets: a continuous unattended run reaches objective 11 of 45 — roughly the first hour, and zero of the sixteen gym badges. Tested objective-by-objective it reaches considerably more targets than that, but reaching a gym leader is not beating one, and the two should not be conflated.

What is honestly unknown: whether it can win a gym battle. The test states built to measure that turned out not to place the game where they claimed, so every gym result so far measured nothing. That is being fixed; until it is, treat gym performance as unknown rather than good or bad.
