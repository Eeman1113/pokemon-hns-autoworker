What it does

Plays the battles properly
Battles are not scripted. The game already ships an AI capable of driving a player-side battler, so Auto Worker points it at your side — real damage calculation, switching, item use. It is the same code that runs your opponents.
Knows where it is in the story
The whole route is pre-declared as an ordered table of objectives. On hand-off the agent reads your save file's own flags to find the furthest point it can prove you have reached, and resumes there. A fresh file and a nine-hour save take the same code path.
Gives control back instantly
The agent writes only the remapped key fields and reads your input only from the raw hardware register, so a real B press can never be confused with one of its own. The A+B+START+SELECT soft reset also keeps working, because raw keys are never touched.
Cannot touch your save
The agent is structurally forbidden from saving. That one rule turns every possible bug from "ruined save file" into "reset and lose the session".

Honest status

This is an early build. The menu entry, the battle hand-off, the input layer and the stage detection are implemented and compile into the ROM. The cross-map router is built from the game's own 4,451 warp connections but is not yet wired to the movement layer, and the objective table covers 30 main-line steps of which 21 were derived from the game's scripts, 7 inferred and 2 unknown.

So: auto-battling and hand-off work. Walking itself across Johto does not yet. Puzzle sections — Ice Path, the Rocket HQ password — are marked hand-back and always will be. Back up your save before trying it.
